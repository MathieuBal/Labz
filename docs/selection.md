# Sélection éditoriale du Labz — 20 octobre 2026

> **Document historique.** Il décrit la sélection décidée le 20 octobre 2026. Depuis, Perfoptimize est revenu dans le catalogue, Pip-Boy est devenu essayable et Constella est présenté en deux produits distincts. Pour l’état courant du portefeuille, utiliser [`portfolio-status.md`](portfolio-status.md).

Le Labz présente une sélection de créations, pas l’inventaire complet des dépôts.
Cette décision porte sur la visibilité dans le Labz : aucun dépôt n’est supprimé,
archivé dans GitHub ou rendu public. Les huit fiches retenues existaient déjà.

## Critères

Une idée identifiable, une expérience ou un usage concret, et suffisamment de
matière pour une présentation honnête. Un bouton de lancement exige en plus
une adresse publique vérifiée. Le potentiel commercial n’est pas démontré par
la présence d’un projet dans cette sélection.

## Base de décision et limites

La revue du portefeuille du 13 octobre examinait documentation, arborescences
et fichiers ciblés. Les README d’EcoRide, Quai Antique, botlecturevlc,
DeezerInfo, Pip-Boy et AtelierFlow ont été relus sur GitHub le 20 octobre.
Cette sélection n’est pas une nouvelle validation de bout en bout des 25
applications ni une estimation de leur valeur financière.

Les anciennes adresses de fiches affichent une explication et un retour vers
la sélection. Les favoris et l’historique ignorent les identifiants retirés ;
les brouillons locaux ne sont pas effacés.

Un projet pourra revenir lorsqu’une expérience montrable, une démonstration ou
un téléchargement vérifié apporte une raison concrète de le visiter. Aucun
dépôt n’est ajouté automatiquement au catalogue.
