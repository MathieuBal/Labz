# Labz 0.19.0 · refonte éditoriale des fiches projet

Cette livraison termine la passe de fond sur les douze fiches du catalogue.

## Objectif

Faire en sorte que chaque page raconte réellement le projet : ce que c’est, pourquoi je l’ai créé, comment l’idée a évolué, ce que l’utilisateur peut faire, ce qui est intéressant techniquement et quel est l’état réel aujourd’hui.

La page Écosystème RP · Zep reste la référence éditoriale : elle donne le niveau de narration recherché sans imposer le même gabarit visuel à tous les projets.

## Fiches reprises

- Sensoria : laboratoire web et exploration des limites pratiques du navigateur.
- Million de Pixels : origine dans une publicité mobile puis transformation de n’importe quelle image en niveau.
- Lootchest : envie personnelle de loot, builds et craft, puis croissance par retours joueurs.
- AFK Farm : Champ magnétique de Sensoria transformé en idle web.
- Diagnostic numérique : cycle réel de douze ateliers, développement rapide puis usage terrain.
- Perfoptimize : lags et crashs sur le PC personnel, mesures sur matériel réel et recommandations corrigées par essais.
- Pip-Boy JDR : téléphone utilisé comme véritable objet de partie, puis ajout de la Console MJ.
- Constella : cartographie subjective des goûts, puis extension organique vers la veille avec Watch.
- Outils d’ateliers mémoire : passage de PowerPoint à des mini-jeux interactifs pour des séances concrètes.
- Crimson’s Blade : organisation chaotique des raids transformée en application de guilde réellement exploitée.
- Écosystème RP : deux arcs distincts, gestion d’entreprise et organisation d’événements.
- Total War AI : expérimentation arrêtée, échec en bataille réelle et limite d’information explicitée.

## Nouveautés

Le journal public est volontairement simplifié. Les micro-versions éditoriales 0.18.1 à 0.18.7 sont regroupées dans la v0.19.0 au lieu de conserver une succession de petites corrections de texte peu utiles pour un visiteur.

## Garde-fous

- narration personnelle à la première personne ;
- faits techniques ancrés dans les audits et le code ;
- limites et échecs explicitement visibles ;
- aucun tiret cadratin dans les textes publics ;
- tests de régression sur les éléments narratifs clés de chaque fiche.
