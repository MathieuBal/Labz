# Présentation Labz — Écosystème RP

## Intention

Conserver la chronologie Saloon → HotzDoggz → ZepRasso → Zepevents, mais faire de chaque étape un mini-dossier produit plutôt qu'une ligne de résumé.

La page doit répondre à six questions pour chaque génération :

1. Quel problème concret devait être supprimé ?
2. Que permettait réellement l'outil ?
3. Comment circulaient les données et les décisions ?
4. Qu'est-ce qui rendait l'outil fiable ou puissant ?
5. Quel usage réel peut être affirmé ?
6. Qu'a appris cette étape pour la suivante ?

## Visuels

Aucune fausse capture ne doit être produite.

Quand le PC permettant de relancer les projets sera disponible :

- Saloon : capture Discord si un serveur ou une archive permet de retrouver l'interface réelle ;
- HotzDoggz : captures du workflow employé/direction et des tableaux persistants, sur serveur de démonstration avec données fictives ;
- ZepRasso : captures visiteur mobile, vote, résultats et administration ;
- Zepevents : captures du dashboard / concours / loterie / caisse dans l'interface CustomTkinter.

En attendant, les flux sont représentés dans Labz par des schémas HTML/CSS explicitement structurels, jamais comme des screenshots.

## Démo future

ZepRasso est le meilleur candidat pour une démo publique autonome, mais seulement après durcissement de l'accès administrateur et des écritures publiques. HotzDoggz est mieux servi par une simulation documentée du workflow que par la connexion à un vrai serveur Discord de production.
